Simplist is a **Progressive Web App (PWA)**.

You can use it directly from your browser or install it on your computer or mobile device for an experience that feels more like a native application.

<Steps>

1. ## Open Simplist

   Open your Simplist instance in a modern web browser.

   Sign in with your account or create a new one.

2. ## Install the app

   <Tabs>

   <TabItem label="Desktop">

   ### <Icon name="laptop" /> Windows, Linux & macOS

   1. Open Simplist using **Google Chrome** or **Microsoft Edge**.
   2. Wait for the page to finish loading.
   3. Click the **Install** button in the address bar.
   4. Confirm the installation.

   Simplist will be added to your operating system's application menu and can be launched like any other desktop application.

   :::tip
   On macOS, Chrome or Edge are recommended, as Safari offers limited support for Progressive Web Apps.
   :::

   </TabItem>

   <TabItem label="Android">

   ### <Icon name="smartphone" /> Android

   1. Open Simplist using **Google Chrome**.
   2. Tap the **⋮** menu.
   3. Select **Install app** or **Add to Home screen**.
   4. Confirm the installation.

   Once installed, Simplist will appear alongside your other applications.

   </TabItem>

   <TabItem label="iPhone & iPad">

   ### <Icon name="smartphone" /> iOS

   1. Open Simplist using **Safari**.
   2. Tap the **Share** button.
   3. Select **Add to Home Screen**.
   4. Tap **Add**.

   Simplist will be available directly from your Home Screen.

   :::tip
   On iPhone and iPad, Safari is required to install the PWA.
   :::

   </TabItem>

   </Tabs>

3. ## Start using Simplist

   Once the installation is complete, you're ready to get started:

   - Create your first list
   - Add tasks
   - Plan your deadlines
   - Share lists with other users

   Continue with the **First Steps** guide to learn the core concepts and features of Simplist.

</Steps>

## Troubleshooting

If you don't see the **Install** button:

- make sure you're using a supported browser;
- verify that your Simplist instance is accessible over **HTTPS**;
- refresh the page and try again.

If the issue persists, contact your instance administrator.
