Congratulations! 🎉 If you've made it here, Simplist is up and running.

This guide will walk you through the basic concepts of the application so you can start organizing your work in just a few minutes.

## The Simplist philosophy

Simplist is designed around a simple idea:

> Organize your work without getting buried in unnecessary complexity.

Instead of projects, workspaces, and dozens of different views, Simplist focuses on a few core building blocks:

- **Lists** to group related tasks
- **Sections** to organize lists
- **Tasks** to track what needs to be done

That's it.

## Create your first list

Lists are the highest level of organization in Simplist.

They can represent anything you want to keep track of, for example:

- 🏠 Home
- 💼 Work
- 🎓 University
- 🛒 Shopping
- ✈️ Travel

To create one:

1. Click **New List**.
2. Give it a name.
3. (Optional) Choose a color.
4. Save it.

## Organize with sections

As your lists grow, sections help keep everything tidy.

For example, a **Home** list could contain:

- Cleaning
- Repairs
- Garden

A **Work** list might contain:

- Backlog
- In Progress
- Completed

Use sections whenever a list starts becoming difficult to navigate.

## Add your first task

Tasks are where you'll spend most of your time.

Each task can include:

- a title
- a due date
- a priority
- additional details

Don't worry about filling every field—many users simply add a title and come back later.

## Stay on top of deadlines

The **Calendar** view collects every task with a due date into a single place.

It's a quick way to answer questions like:

- What should I work on today?
- What's due this week?
- What have I forgotten?

## Share lists

Need to collaborate?

You can share a list with other Simplist users so everyone can view and manage the same tasks together.

This is perfect for:

- Family shopping lists
- Team task tracking
- Event planning
- Household chores

## Speed up your workflow

Simplist is designed to be **keyboard-first**.

Use keyboard shortcuts and the command palette to navigate quickly, create tasks, and perform common actions without leaving the keyboard.

As you become familiar with the application, you'll find that many actions can be completed in just a few keystrokes.
