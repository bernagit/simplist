Open the settings from your profile menu at the top of the sidebar, or with <kbd>Ctrl</kbd> + <kbd>,</kbd>.

## General

- **Language**: English or Italian.
- **Default view**: what opens when you launch Simplist. It can be Home, the Calendar or one of your lists.
- **Start of week**: Monday or Sunday, for the calendar.
- **Confirmation**: ask before archiving or deleting a list.

## Account

- **Profile**: name, email and avatar.
- **Password**: changing it needs the current one. If you forgot it, use **Forgot password?** on the sign-in page; it works when the instance has email set up.

## Appearance

- **Theme**: light, dark or the system's.
- **Accent color**: the color of buttons, links and highlighted elements.
- **Sync appearance across devices**: saves the theme and color on your account instead of only on this device.

## Notifications and Invites

See [Notifications](/docs/en/user-guide/notifications/) and [Invites](/docs/en/user-guide/sharing/#invites).

## Info

The installed version, links to the code and the documentation, and the **changelog** with what's new in each version. The changelog opens by itself the first time after an update.

## Keyboard shortcuts

Simplist works well without a mouse too. The full list is always at hand with <kbd>Shift</kbd> + <kbd>H</kbd>.

| Action | Keys |
|---|---|
| Search | <kbd>Ctrl</kbd> + <kbd>K</kbd> |
| New list | <kbd>Ctrl</kbd> + <kbd>L</kbd> |
| Edit the open list | <kbd>Shift</kbd> + <kbd>E</kbd> |
| Share the open list | <kbd>Shift</kbd> + <kbd>S</kbd> |
| Show or hide the sidebar | <kbd>M</kbd> |
| Switch light/dark theme | <kbd>Ctrl</kbd> + <kbd>J</kbd> |
| Settings | <kbd>Ctrl</kbd> + <kbd>,</kbd> |
| Keyboard shortcuts | <kbd>Shift</kbd> + <kbd>H</kbd> |
| Go to Home | <kbd>G</kbd> then <kbd>G</kbd> |
| Go to the Calendar | <kbd>G</kbd> then <kbd>C</kbd> |
| Go to My Lists | <kbd>G</kbd> then <kbd>L</kbd> |
| Go to Shared With Me | <kbd>G</kbd> then <kbd>S</kbd> |

On a Mac use <kbd>⌘</kbd> instead of <kbd>Ctrl</kbd> for search.
