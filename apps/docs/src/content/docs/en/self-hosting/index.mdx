Simplist is installed with **Docker Compose**. Images are published on GitHub Container Registry (`ghcr.io/bernagit`), so nothing is built on your server: the whole instance is described by a single `compose.yaml`, configured with a `.env` file.

## What an installation is made of

| Service | Image | Role |
|---|---|---|
| `db` | `postgres:17` | PostgreSQL database with all the data |
| `api` | `ghcr.io/bernagit/simplist-api` | Express API: authentication, lists, tasks, reminders |
| `app` | `ghcr.io/bernagit/simplist-app` | Next.js web app (installable as a PWA) |
| `docs` | `ghcr.io/bernagit/simplist-docs` | This documentation, under `/docs/` (optional, `docs` profile) |
| `proxy` | `ghcr.io/bernagit/simplist-proxy` | Single entry point: nginx with the routing built in |

Traffic only comes in through the **proxy**, on port `3000` of the host (`HTTP_PORT`):

- `/api/*` goes to the API;
- `/docs/*` goes to the documentation; without the `docs` service it redirects to the documentation sources on GitHub;
- everything else goes to the web app.

App, API and documentation are on the **same domain**: session cookies work without any CORS setup, and no extra DNS record is needed. The database isn't published, only the API reaches it.

```text
Browser ──HTTPS──▶ reverse proxy (Caddy, nginx, Traefik…) ──HTTP──▶ proxy :3000
                                                                    ├── /api   ─▶ api :2000 ─▶ db :5432
                                                                    ├── /docs  ─▶ docs :80
                                                                    └── /      ─▶ app :3000
```

## Requirements

- A Linux server with **Docker** and the **Docker Compose** plugin (v2).
- About **1 GB of free RAM** and a few GB of disk for the database.
- A **domain** and an **HTTPS certificate**. HTTPS is needed for:
  - session cookies, which are `Secure`;
  - installing the app (PWA);
  - push notifications.
- Optional: an **SMTP** server, for the welcome email, email invites and password reset.
