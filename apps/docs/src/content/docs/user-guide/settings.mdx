Apri le impostazioni dal menu del tuo profilo, in cima alla barra laterale, oppure con <kbd>Ctrl</kbd> + <kbd>,</kbd>.

## Generale

- **Lingua**: italiano o inglese.
- **Vista predefinita**: cosa aprire all'avvio. Può essere la Home, il Calendario o una delle tue liste.
- **Inizio della settimana**: lunedì o domenica, per il calendario.
- **Conferma eliminazione**: chiedere conferma prima di archiviare o eliminare una lista.

## Account

- **Profilo**: nome, email e avatar.
- **Password**: per cambiarla serve quella attuale. Se l'hai dimenticata, usa **Password dimenticata** nella pagina di accesso; funziona se l'istanza ha l'email configurata.

## Aspetto

- **Tema**: chiaro, scuro o quello del sistema.
- **Colore d'accento**: il colore di pulsanti, link ed elementi in evidenza.
- **Sincronizza l'aspetto su tutti i dispositivi**: salva tema e colore nel tuo account invece che solo su questo dispositivo.

## Scorciatoie da tastiera

Simplist si usa bene anche senza mouse. L'elenco completo è sempre a portata di mano con <kbd>Shift</kbd> + <kbd>H</kbd>.

| Azione | Tasti |
|---|---|
| Ricerca | <kbd>Ctrl</kbd> + <kbd>K</kbd> |
| Nuova lista | <kbd>Ctrl</kbd> + <kbd>L</kbd> |
| Modifica la lista aperta | <kbd>Shift</kbd> + <kbd>E</kbd> |
| Condividi la lista aperta | <kbd>Shift</kbd> + <kbd>S</kbd> |
| Mostra o nascondi la barra laterale | <kbd>M</kbd> |
| Cambia tema chiaro/scuro | <kbd>Ctrl</kbd> + <kbd>J</kbd> |
| Impostazioni | <kbd>Ctrl</kbd> + <kbd>,</kbd> |
| Scorciatoie da tastiera | <kbd>Shift</kbd> + <kbd>H</kbd> |
| Vai alla Home | <kbd>G</kbd> poi <kbd>G</kbd> |
| Vai al Calendario | <kbd>G</kbd> poi <kbd>C</kbd> |
| Vai a Le mie liste | <kbd>G</kbd> poi <kbd>L</kbd> |
| Vai a Condivise con me | <kbd>G</kbd> poi <kbd>S</kbd> |

Su Mac usa <kbd>⌘</kbd> al posto di <kbd>Ctrl</kbd> per la ricerca.
