Simplist è una **Progressive Web App (PWA)**.

Puoi utilizzarla direttamente dal browser oppure installarla sul tuo computer o dispositivo mobile per ottenere un'esperienza più simile a quella di un'applicazione nativa.

<Steps>

1. ## Apri Simplist

   Apri l'indirizzo della tua istanza Simplist con un browser moderno.

   Accedi con il tuo account oppure registrati.

2. ## Installa l'app

   <Tabs>

   <TabItem label="Desktop">

   ### Windows, Linux e macOS

   1. Apri Simplist con **Google Chrome** oppure **Microsoft Edge**.
   2. Attendi il caricamento della pagina.
   3. Fai clic sul pulsante **Installa** nella barra degli indirizzi.
   4. Conferma l'installazione.

   L'app verrà aggiunta al menu delle applicazioni del sistema operativo.

   :::tip
   Su macOS è consigliato utilizzare Chrome o Edge, poiché Safari offre un supporto limitato alle Progressive Web App.
   :::

   </TabItem>

   <TabItem label="Android">

   ### <Icon name="smartphone" /> Android

   1. Apri Simplist con **Google Chrome**.
   2. Tocca il menu **⋮**.
   3. Seleziona **Installa app** oppure **Aggiungi alla schermata Home**.
   4. Conferma.

   Una volta completata l'installazione, Simplist comparirà tra le applicazioni del dispositivo.

   </TabItem>

   <TabItem label="iPhone & iPad">

   ### <Icon name="smartphone" /> iOS

   1. Apri Simplist con **Safari**.
   2. Tocca il pulsante **Condividi**.
   3. Seleziona **Aggiungi alla schermata Home**.
   4. Tocca **Aggiungi**.

   Simplist sarà disponibile direttamente nella schermata Home.

   :::tip
   Su iPhone e iPad è necessario utilizzare Safari per installare la PWA.
   :::

   </TabItem>

   </Tabs>

3. ## Inizia a utilizzare Simplist

   Dopo l'installazione puoi iniziare subito a organizzare il tuo lavoro:

   - Crea la tua prima lista
   - Aggiungi attività
   - Pianifica le scadenze
   - Condividi le liste con altri utenti

   Continua con la guida **Primi passi** per scoprire tutte le funzionalità dell'applicazione.

</Steps>

## Risoluzione dei problemi

Se non visualizzi il pulsante **Installa**:

- verifica di utilizzare un browser supportato;
- assicurati che l'istanza sia raggiungibile tramite **HTTPS**
- aggiorna la pagina e riprova.

Se il problema persiste, contatta l'amministratore dell'istanza.
