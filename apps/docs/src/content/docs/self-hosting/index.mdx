Simplist si installa con **Docker Compose**. Le immagini sono pubblicate su GitHub Container Registry (`ghcr.io/bernagit`), quindi sul server non serve compilare nulla.

## Come è fatta un'installazione

| Servizio | Immagine | Ruolo |
|---|---|---|
| `db` | `postgres:17` | Database PostgreSQL con tutti i dati |
| `api` | `ghcr.io/bernagit/simplist-api` | API Express: autenticazione, liste, attività, promemoria |
| `app` | `ghcr.io/bernagit/simplist-app` | Web app Next.js (installabile come PWA) |
| `docs` | `ghcr.io/bernagit/simplist-docs` | Questa documentazione (facoltativa) |
| `nginx` | `nginx:1.27-alpine` | Unico punto d'ingresso: instrada le richieste agli altri servizi |

Il traffico entra solo da **nginx**, sulla porta `3000` dell'host:

- `/api/*` va all'API;
- tutto il resto va alla web app;
- le richieste a un host che inizia con `docs.` (per esempio `docs.esempio.it`) vanno alla documentazione.

App e API stanno quindi sullo **stesso dominio**: i cookie di sessione funzionano senza configurazioni CORS.

```text
Browser ──HTTPS──▶ reverse proxy (Caddy, nginx, Traefik…) ──HTTP──▶ simplist-nginx :3000
                                                                    ├── /api  ─▶ api :2000 ─▶ db :5432
                                                                    ├── /     ─▶ app :3000
                                                                    └── docs.* ─▶ docs :80
```

## Requisiti

- Un server Linux con **Docker** e il plugin **Docker Compose** (v2).
- Circa **1 GB di RAM** libera e qualche GB di disco per il database.
- Un **dominio** e un **certificato HTTPS**. L'HTTPS è necessario per:
  - i cookie di sessione, che sono `Secure`;
  - l'installazione come app (PWA);
  - le notifiche push.
- Facoltativo: un server **SMTP**, per l'email di benvenuto, gli inviti via email e il recupero della password.
