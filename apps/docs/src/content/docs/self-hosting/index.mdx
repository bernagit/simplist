Simplist si installa con **Docker Compose**. Le immagini sono pubblicate su GitHub Container Registry (`ghcr.io/bernagit`), quindi sul server non serve compilare nulla: tutta l'istanza è descritta da un solo `compose.yaml`, configurato con un file `.env`.

## Come è fatta un'installazione

| Servizio | Immagine | Ruolo |
|---|---|---|
| `db` | `postgres:17` | Database PostgreSQL con tutti i dati |
| `api` | `ghcr.io/bernagit/simplist-api` | API Express: autenticazione, liste, attività, promemoria |
| `app` | `ghcr.io/bernagit/simplist-app` | Web app Next.js (installabile come PWA) |
| `docs` | `ghcr.io/bernagit/simplist-docs` | Questa documentazione, su `/docs/` (facoltativa, profilo `docs`) |
| `proxy` | `ghcr.io/bernagit/simplist-proxy` | Unico punto d'ingresso: nginx con l'instradamento già configurato |

Il traffico entra solo dal **proxy**, sulla porta `3000` dell'host (`HTTP_PORT`):

- `/api/*` va all'API;
- `/docs/*` va alla documentazione; senza il servizio `docs` rimanda ai sorgenti della documentazione su GitHub;
- tutto il resto va alla web app.

App, API e documentazione stanno sullo **stesso dominio**: i cookie di sessione funzionano senza configurazioni CORS, e non serve nessun record DNS in più. Il database non è pubblicato: lo raggiunge solo l'API.

```text
Browser ──HTTPS──▶ reverse proxy (Caddy, nginx, Traefik…) ──HTTP──▶ proxy :3000
                                                                    ├── /api   ─▶ api :2000 ─▶ db :5432
                                                                    ├── /docs  ─▶ docs :80
                                                                    └── /      ─▶ app :3000
```

## Requisiti

- Un server Linux con **Docker** e il plugin **Docker Compose** (v2).
- Circa **1 GB di RAM** libera e qualche GB di disco per il database.
- Un **dominio** e un **certificato HTTPS**. L'HTTPS è necessario per:
  - i cookie di sessione, che sono `Secure`;
  - l'installazione come app (PWA);
  - le notifiche push.
- Facoltativo: un server **SMTP**, per l'email di benvenuto, gli inviti via email e il recupero della password.
